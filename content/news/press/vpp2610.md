**VPP 26.10 Release on 28th of October 2026** -- The VPP 26.10 Release includes multiple new features such as Marvell
Octeon device driver enhancements (hardware traffic management, ROC update, and link-speed support), AF_XDP
multi-buffer support, DPDK 26.07 with Intel QAT 420xx series support, significant TCP improvements (DSACK receiver per
RFC 2883, RACK loss detection and Tail Loss Probe per RFC 8985, and BBRv3 congestion control), Traffic Management
`mark_flow` action, flow template and async range infrastructure, interface link-speed set API, HTTP static server
control APIs, and others. More than 556 commits were merged since the previous release, including 228 fixes.
Complete list of features and bug fixes can be found in the Release Notes
[here](https://fd.io/docs/vpp/master/aboutvpp/releasenotes/v26.10.html#features)!

**Release Highlight:** Starting with VPP 27.02, libvnet will be built with hidden symbol visibility by default (not
enabled by default in 26.10). Out-of-tree plugins and applications linking against libvnet should verify required
symbols using the provided checker tooling before upgrading further.
